Chapter 2
Project Planning and Requirements Analysis

This chapter presents the project planning methodology adopted for the Al Jazeera STCA olive oil quality management platform. We selected the Scrum agile framework to organize development into iterative, deliverable increments over the two-month project timeline.

6. Agile Scrum Methodology

6.1 Scrum Framework Overview

Scrum structures development work into fixed-length cycles called sprints. Each sprint produces a working, testable software increment. The three core Scrum artifacts used in this project are:

  • Product Backlog – a prioritized list of all desired features and user stories for the full application.
  • Sprint Backlog – the subset of items selected for a given sprint, broken into concrete development tasks.
  • Product Increment – the working, tested feature set delivered at the end of each sprint.

The project spans two months and is organized into four sprints of approximately two weeks each, covering five user roles: Administrator, Collector, Panel Member, Panel Evaluation Supervisor, and Laboratory Technician. All roles additionally share a common base of authentication and profile management capabilities.

ActorAdministrator
